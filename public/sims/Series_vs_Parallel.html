For the curious — the general rule

Take an ideal voltage source V and n identical bulbs of resistance R. Baseline brightness is normalised to 100% in both topologies, because the demo is about relative change on failure, not absolute wattage.

Series. Total resistance is nR, so current is I = V/(nR) and each bulb dissipates P = I²R = V²/(n²R). If one filament opens with no shunt, the circuit breaks: I = 0 everywhere and all n bulbs go dark.

If a shunt is present, the dead bulb becomes a short (≈ 0 Ω) instead of a break, so the loop stays closed through n−1 bulbs. Each survivor now dissipates P' = V²/((n−1)²R), so:

brightness multiplier = P'/P = n² / (n−1)²

Strand length nSurvivor brightness
33²/2² = 9/4 = 225.0%
66²/5² = 36/25 = 144.0%
2020²/19² = 400/361 = 110.8%

Shorter strands surge much harder per failure. That surge is also cumulative: after k failures the survivors run at n²/(n−k)² of original power, which is why an old string dies faster and faster — each loss raises the stress on everything left, driving the next failure sooner.

The shunt mechanism. A wire is wrapped around the bulb base and coated in insulating enamel, so it normally carries nothing. When the filament opens, the full supply voltage appears across that one gap; the resulting spike punches through the enamel and the shunt begins conducting, restoring the loop.

Parallel. Each bulb sits directly across the source with its own path, so P = V²/R for each, independent of n. Removing one path leaves the others' voltage untouched, so survivors stay at exactly 100%. This holds only because the source is modelled as ideal — with a real internal resistance r, removing a load slightly raises terminal voltage and the survivors would brighten by a small amount.
